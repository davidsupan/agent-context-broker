# Security policy

## Supported versions

Agent Context Broker is currently beta. Until the first GitHub prerelease is
published, security fixes are supported on the latest `main` revision. After
that, only the latest published beta is supported. Older releases and forks are
not covered.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/davidsupan/agent-context-broker/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected version, provider and platform, impact, and the smallest
safe reproduction. Never attach real transcripts, credentials, tokens, personal
paths, internal URLs, or proprietary organizational data.

The maintainer will acknowledge the report, assess impact and affected versions,
coordinate a fix and validation, and agree on disclosure timing with the
reporter. This beta does not offer a guaranteed response or remediation SLA.
