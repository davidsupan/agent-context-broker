# Support

Agent Context Broker is a maintainer-led beta and does not have a support SLA.

## Where to ask

- Use [GitHub Discussions](https://github.com/davidsupan/agent-context-broker/discussions)
  for setup help, design questions, and feature proposals.
- Use the [bug report form](https://github.com/davidsupan/agent-context-broker/issues/new?template=bug_report.yml)
  for a reproducible defect in a supported provider or platform.
- Use [private vulnerability reporting](https://github.com/davidsupan/agent-context-broker/security/advisories/new)
  for suspected security vulnerabilities.

Include the broker version or commit, provider, operating system, Bun version,
and the smallest synthetic reproduction. Remove credentials, transcripts,
personal paths, internal URLs, and proprietary data before posting.

Until the first GitHub prerelease is published, support is limited to the latest
`main` revision. After that, only the latest beta is supported. For contribution
scope and local validation, see [CONTRIBUTING.md](CONTRIBUTING.md).
