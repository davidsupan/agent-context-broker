# Code of conduct

## Our standard

Be respectful, specific, and constructive. Disagreement about designs and
tradeoffs is welcome; harassment, discrimination, intimidation, personal
attacks, and disclosure of another person's private information are not.

Project spaces include issues, Discussions, pull requests, reviews, and other
public communication used to coordinate this repository.

## Data safety

This project works near agent histories and local developer environments. Never
post real transcripts, credentials, tokens, personal paths, internal URLs, or
proprietary organizational data. Use synthetic reproductions and redact logs
before sharing them.

## Enforcement

Maintainers may edit or remove contributions that violate these expectations
and may temporarily or permanently restrict participation. Enforcement should
be proportionate, documented when appropriate, and focused on protecting the
community and the project.

Report conduct concerns privately through a contact method on the maintainer's
GitHub profile. Do not put sensitive details in a public issue. Security
vulnerabilities follow the separate process in [SECURITY.md](SECURITY.md).
