# Governance

Agent Context Broker is a maintainer-led open-source project. The maintainer is
responsible for roadmap, architecture, releases, security response, and final
merge decisions.

## Decision process

Substantial changes begin as a GitHub Discussion or issue. A decision is ready
for implementation when the maintainer has explicitly accepted its scope and
recorded the intended behavior or constraints. Repository code, schemas,
tests, and release notes are the durable record once the change is merged.

Feedback and competing designs are welcome. Consensus is useful but is not a
requirement for a decision; the maintainer resolves tradeoffs and may defer or
decline proposals that increase privacy risk, provider coupling, maintenance
cost, or contract instability.

## Contributions

Pull requests are accepted for previously approved work only. This keeps review
focused and avoids asking contributors to invest in changes that are unlikely
to be integrated. See [CONTRIBUTING.md](CONTRIBUTING.md) for the complete flow.

## Security and conduct

Security reports follow [SECURITY.md](SECURITY.md). Participation is governed
by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
